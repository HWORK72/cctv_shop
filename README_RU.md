Полнофункциональная веб-платформа электронной коммерции на базе Django для каталогизации, администрирования и онлайн-продажи оборудования систем видеонаблюдения и безопасности.

### Архитектурные особенности:
* **Реляционная модель данных:** Проектирование структурированных схем каталога оборудования (CCTV камеры, регистраторы, аксессуары) через Django ORM.
* **Кастомная панель управления:** Расширенные административные интерфейсы Django для гибкого управления товарной номенклатурой, складскими остатками и заказами.
* **Система аутентификации пользователей:** Регистрация, авторизация и управление профилями клиентов с сессионной изоляцией.
* **Модульная структура MVC:** Четкое разделение моделей данных, маршрутов маршрутизации (URLs), логики контроллеров (Views) и интерфейсных шаблонов.

### Стек технологий:
* Python 3.12
* Django 5.x (Веб-каркас и ORM)
* SQLite / PostgreSQL (Реляционная база данных)
* HTML5 / CSS3 / JavaScript (Адаптивный клиентский интерфейс)
